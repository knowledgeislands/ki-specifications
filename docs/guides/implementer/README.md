# Implementer guides

These guides are for someone building against what the specification corpus publishes: a KIS document, the Knowledge Package schema, a template, or an example package. They rely only on those published artefacts.

Knowledge Islands is pre-v1, and no KIS document is currently published. The schema, templates, and examples are illustrative until a specification adopts them.

## Guides

- [Implementing an accepted KIS](implementing-an-accepted-kis.md) - check what a specification's status and version promise, build against its normative text, validate your output, and report what you learn.
