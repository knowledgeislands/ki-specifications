# Guides

These guides explain how to do practical work with the Knowledge Islands specification corpus: how to propose a change to it, and how to build against what it publishes. They say how to do something; the governance and process documents remain the authority for what is true.

## Current posture

Knowledge Islands is pre-v1. While it remains at v0.x, this repository accepts no new KIPs or KIS documents, and repository-level specifications stay in the repository that owns each implementation. The guides describe the process that will apply once the overall v1 boundary has been reviewed, and each one says first what to do today.

## Choose your route

- [Contributor guides](contributor/README.md) - for someone changing the corpus: deciding whether a change needs a proposal, and raising and stewarding a KIP.
- [Implementer guides](implementer/README.md) - for someone building against a published specification, schema, template, or example.
